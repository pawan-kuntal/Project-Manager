Project Manager – Kanban Board

A real-world Project Management Kanban tool built to manage tasks, workflows, and team collaboration efficiently.
This application focuses on usability, state management, and scalable frontend architecture, not just UI.


🚀 Features:-

1.Kanban Workflow:-
Columns: Todo → In Progress → Done
Smooth task movement using Drag & Drop

2.User Authentication:-
Secure login system
User-specific access and sessions

3.Task Management:-
Create, update, delete tasks
Assign tasks to specific users
Track task status visually

4.Collaboration:-
Multiple users can work on the same board
Real-time task updates (client-side sync)

5.Customization:-
Theme switching (Light / Dark)
Language support for better accessibility

6.Responsive UI

Works across desktop and mobile devices



🛠 Tech Stack:-

1.Frontend: React, JavaScript (ES6+)
2.Styling: HTML5, CSS3
3.State Management: React Hooks
4.Drag & Drop: Native Drag & Drop APIs
5.Authentication: Custom auth logic
6.Version Control: Git & GitHub



🧠 What This Project Demonstrates:-

1.Real-world React component architecture
2.Efficient state handling across multiple components
3.Clean folder structure for scalability
4.Authentication flow implementation
5.Problem-solving mindset beyond tutorials
6.UX-focused frontend development



🔑 Authentication Flow:-

1.User logs in
2.Session is created and maintained
3.Authorized users can access and manage boards
4.Tasks are linked to users for accountability



📈 Future Improvements:-

1.Backend integration (Node.js / Firebase)
2.Real-time sync using WebSockets
3.Role-based permissions (Admin / Member)
4.Activity logs & notifications
5.Persistent database storage
